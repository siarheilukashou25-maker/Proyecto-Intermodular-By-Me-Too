# Proyecto Intermodular DAM

Repositorio destinado a la **gestión y documentación de las tareas relacionadas con el proyecto de Desarrollo de Aplicaciones Multiplataforma (DAM)**.

En este repositorio se almacenará la documentación y el material necesario para desarrollar y justificar el proyecto. El código fuente de la aplicación se encuentra en un repositorio independiente.

---

## 📱 Sobre el proyecto

El proyecto consiste en desarrollar una aplicación para **gestionar y repartir los gastos de compras compartidas entre personas que viven juntas**.

La aplicación permitirá registrar los productos adquiridos, indicar para quién se ha realizado cada compra y calcular automáticamente cómo debe repartirse el coste entre los miembros del grupo.

Por ejemplo, una persona puede realizar una compra que incluya productos para todos los miembros de la vivienda y otros productos destinados únicamente a una persona concreta. La aplicación permitirá diferenciar ambos casos y calcular posteriormente cuánto corresponde pagar a cada miembro.

El objetivo es facilitar la gestión de los gastos comunes y evitar cálculos manuales al finalizar un período de tiempo determinado.

## 🏷️ Nomenclatura de las tareas

Cada tarea sigue una nomenclatura específica en función de la asignatura a la que pertenece:

* **DI-** → tareas relacionadas con **Diseño de Interfaces**.
* **PD-** → tareas relacionadas con **Proyecto Intermodular**.

Esta nomenclatura permite identificar rápidamente a qué asignatura corresponde cada tarea.

## 📂 Contenido del repositorio

Este repositorio contiene principalmente la **documentación y las tareas del proyecto**.

La documentación seguirá la estructura establecida para el Proyecto Intermodular, incluyendo aspectos como:

* Introducción y contexto del proyecto.
* Análisis del problema y de la necesidad.
* Objetivos y alcance.
* Análisis de requisitos.
* Diseño de la solución.
* Planificación.
* Desarrollo e implementación.
* Pruebas.
* Despliegue.
* Manuales.
* Resultados y conclusiones.
* Anexos y documentación complementaria.

El repositorio se irá completando a medida que se desarrollen las diferentes partes del proyecto.


### 🔎 Buscar y filtrar tareas

Las tareas pueden localizarse utilizando las opciones de búsqueda y filtrado disponibles en GitHub.

Es posible:

* Buscar tareas por palabras clave.
* Filtrar por **labels**.
* Consultar las tareas de una asignatura concreta.
* Consultar diferentes estados dentro del tablero Kanban.
* Acceder desde una tarea a la documentación o archivos relacionados.
